# ソリューション営業のための生成AIセキュア活用実践 — 研修コンテンツ一式

ELIソリューションズの営業担当者として **架空の研修提案** を進めながら、
生成AI（Microsoft Copilot／Microsoft 365 Premium）と Office（Word・Excel・PowerPoint）を
業務で使う体験を積む 2 日間の研修です。

| 項目 | 内容 |
|---|---|
| 講座タイトル | ソリューション営業のための生成AIセキュア活用実践 |
| 日数・時間 | 2日間／各日 9:30〜17:00（昼休憩 12:00〜13:00） |
| 受講者数 | 1回あたり 3名程度 |
| 使用ツール | Microsoft 365 Premium（Copilot）、Word・Excel・PowerPoint、（任意）OpenAI Codex |
| 構成比 | **約3/4**：生成AIの基礎・セキュリティ・Office連携の演習 ／ **約1/4**：自社アプリ紹介と営業業務への応用 |

## 研修ストーリー

受講者は **ELIソリューションズ** の営業担当者として、架空の顧客 **みらい商事株式会社**（東京都）から
「法人営業20名向けの生成AI活用研修」の相談を受けます。商談の内容は `materials/03_商談文字起こし_初回訪問` を正とします。

- 全社約300名。Microsoft 365 を全社で利用し、一部の部署で Copilot を試行中
- A案：集合研修2日間＋教材 60万円／B案：A案＋事前診断＋受講後1か月の活用フォロー 100万円（税抜・20名）
- 予算の目安は100万円（承認済みの上限ではない）。最終的な承認者は金額確定後に確認
- Copilot の利用可否、A案の場合のフォロー担当、実施日・会場は未確定

日程：初回訪問 10/6（火）→ 骨子送付 10/9（金）→ 顧客からの資料受領 10/12（月）・10/13（火）
→ 提案（A案・B案の提案書と概算）10/16（金）14:00 → 研修実施 11月上旬
事前調査 → ヒアリング準備 → 商談議事録 → フォローメール → データ分析・見積 → 提案書 → 提案スライド
という提案プロセスを、すべて Copilot を使って進めます。

最後に、商談後の作業（議事録・メール下書き・行動管理）を支援する自社アプリ
**「ELI Sales Assist」** を紹介し、受講者が自分の営業業務にどう応用するかを考えます。
開発環境がある受講者は、Codex で同じアプリを段階的に作り、不具合を直しながら完成に近づけます。

## フォルダ構成

```
docs/        研修設計・テキスト・講師ガイドなど（Markdown が原本）
  00_研修企画書.md                  … 顧客向けの研修提案書（講座概要・到達目標・前提環境）
  01_カリキュラム_タイムテーブル.md   … 2日間の分単位タイムテーブルと 3/4・1/4 の配分
  02_受講者テキスト.md              … 講義パートの本文（第1章〜第10章）
  03_演習ガイド.md                  … 演習1〜14 の手順・プロンプト例・確認ポイント
  04_セキュア活用ガイドライン.md     … 1枚もののチェックシート（持ち帰り用）
  05_講師ガイド.md                  … 進め方・声かけ・想定トラブル・事前準備
  06_環境準備チェックリスト.md       … 受講者・講師の事前準備
  07_理解度確認テスト・アンケート.md
  08_応用ワークシート.md             … 第10章 業務応用ワークショップ用
  word/                             … 上記 Markdown から生成した配布用 .docx
materials/   演習素材（すべて架空データ。Word/Excel/テキスト）
codex/       Codex 段階開発プロンプト集（不具合修正ストーリー付き）と確認用データ（testdata/）
app/         ELI Sales Assist の参照実装（講師デモ用・完成形）
tools/       素材・配布物の生成スクリプト
slides/      講義スライド（ELIテンプレート／フェーズ5で作成）
```

## 開発フェーズ

| フェーズ | 内容 | 状態 |

| 1 | 研修企画書・カリキュラム・タイムテーブル | 完了 |

| 3 | 講師ガイド・環境準備・テスト/アンケート・ガイドライン | 完了 |

| 5 | 講義スライド（ELI PowerPoint テンプレート・全70枚程度） | 1〜36枚目 作成済み（`python tools/build_slides.py` で再生成） |

## 再生成

```bash
pip install openpyxl python-docx
python tools/build_materials.py   # materials/ の Word・Excel 素材を生成
python tools/md_to_docx.py        # docs/*.md → docs/word/*.docx
```

> **注意**：Copilot の機能名・画面・利用上限は頻繁に変わります。本教材は 2026年9月時点の想定で作成しています。
> 実施前に `docs/06_環境準備チェックリスト.md` の「講師による機能確認」を必ず行ってください。
