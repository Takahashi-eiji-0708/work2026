# 付箋（スティッキーノート）アドオン — Edifist Cockpit 用

業務コックピット（Edifist Cockpit ポータブル版）の画面上に、自由に貼れる付箋を追加します。
Next.js のビルド成果物（`.next/`）には手を入れず、`server.js` に 1 行足すだけで動きます。

## できること

- 右下の「＋ 付箋」ボタン（または `Alt+N`）で付箋を追加
- 上部のバーをドラッグして移動、右下の角をドラッグしてサイズ変更
- 5 色（黄・ピンク・青・緑・紫）の切り替え、× で削除（内容がある場合は確認あり）
- 「付箋を隠す／表示」で一時的にまとめて非表示
- 内容・位置・サイズ・色は自動保存（`data/stickies.json`）。予定・ToDo と同じく `data\` に入るので、フォルダごとコピーすれば別 PC へ移せます

## ファイル

| ファイル | 役割 |
|---|---|
| `hook.cjs` | サーバー側。`/api/stickies`（GET/PUT）と静的ファイルを提供し、HTML 応答の末尾に付箋スクリプトを差し込む |
| `stickies.js` | 画面側。付箋の表示・編集・ドラッグ・保存 |
| `stickies.css` | 見た目。コックピットの配色変数（`--amber` など）に合わせている |

## 組み込み方（ポータブル版）

1. このフォルダの 3 ファイルを、ポータブル版フォルダ内の `stickies\` にコピーする
2. `server.js` の 1 行目（`const path = require('path')`）の直後に次の 1 行を追加する

   ```js
   require('./stickies/hook.cjs')
   ```

3. いつもどおり `start.bat`（または `起動.bat`）で起動する

## 再パッケージ（`npm run package`）するとき

`npm run build` で `server.js` は作り直されるため、上の手順 2 をやり直すか、
`scripts/package.ps1` に「`stickies\` のコピー」と「`server.js` への 1 行追加」を加えてください。
