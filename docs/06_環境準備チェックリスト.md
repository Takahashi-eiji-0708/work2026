# 環境準備チェックリスト

## 1. 受講者の事前準備（研修の1週間前までに案内）

### 必須

- [ ] Microsoft 365 Premium が有効な Microsoft アカウント（ID・パスワードを当日すぐ入力できること）
- [ ] Word・Excel・PowerPoint（デスクトップ版推奨。Web 版でも可）に上記アカウントでサインインできる
- [ ] OneDrive にサインインでき、**自動保存** がオンになる
- [ ] Microsoft Edge で Copilot にサインインできる

### 開発トラック希望者のみ

- [ ] Python 3.11 以上（`python --version` で確認）
- [ ] Git
- [ ] OpenAI Codex（CLI：`codex --version`、または VS Code などの IDE 拡張）が起動し、サインインできる
- [ ] （任意）OpenAI API キー。**なくてもモックモードで最後まで進められる**
- [ ] 会社の PC を使う場合、ソフトウェアのインストールと外部 API への通信が許可されている
