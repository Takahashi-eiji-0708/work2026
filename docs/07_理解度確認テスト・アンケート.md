| 1 | 顧客のホームページに載っている従業員数は、Copilot に入力してよい？ | よい（A） | 公開情報。ただし他の情報と組み合わせて社名が特定される点には注意 |

## 2. 最終理解度テスト（10問・選択式・10分）

**問1** 大規模言語モデル（LLM）の基本的な仕組みとして最も適切なものはどれか。
1. インターネットをその都度検索して、正しい答えを探して返す

4. 質問ごとに専門家が回答を用意している

**問2** 生成AIが事実と異なる内容をもっともらしく出力することを何と呼ぶか。
1. プロンプトインジェクション　2. ハルシネーション　3. ファインチューニング　4. マスキング

**問3** プロンプトの4要素として本研修で紹介したものの組み合わせはどれか。
1. 役割・目的・前提・出力形式　2. 挨拶・質問・お礼・署名　3. 日時・場所・人・金額　4. 要約・翻訳・生成・検索

**問4** 次のうち「C：入力不可」に当たるものはどれか。
1. 業界の一般的な動向　2. 顧客のニュースリリースの内容　3. 顧客から口外しないよう頼まれた支社統合の計画　4. 自分で考えた研修の一般的なアイデア

**問5** 「競合は2日間の研修を1名あたり約4万円で提案しているらしい」を「競合は中程度の価格帯で提案」と書き換える技法はどれか。
1. 置換　2. 一般化　3. 削除　4. 抽象化

**問6** Excel の Copilot で分析する前にしておくべきこととして、**適切でない** ものはどれか。

**問7** Copilot が作成した見積の数式について、最も適切な扱いはどれか。
1. Copilot が作ったので確認は不要　2. 数式の意味を確認し、一部を電卓などで検算する　3. 数式を削除して値だけを貼り付ける　4. 別の AI に同じ見積を作らせて平均をとる

**問8** PowerPoint で Word の提案書からスライドを作るとき、品質を上げるために元の Word でしておくとよいことはどれか。
1. 文字をすべて太字にする　2. 見出しスタイル（見出し1・見出し2）を正しく付ける　3. 表をすべて画像にする　4. ページ番号を削除する

**問9** ELI Sales Assist で、AI に送る前にマスキングした名前を、出力後に元に戻す処理が必要な理由として最も適切なものはどれか。
1. AI の処理速度を上げるため　2. 置換表を AI に渡さずに、読みやすい最終文書を作るため　3. データベースの容量を減らすため　4. 著作権を守るため

**問10** アプリ開発でコーディングエージェントに不具合を伝えるときの伝え方として、最も適切なものはどれか。
1. 「動きません。直してください」

## 3. 研修アンケート

| No | 質問 | 回答方法 |
|---|---|---|
| 1 | 研修全体の満足度 | 5段階 |
| 2 | 研修内容は業務に役立つと思いますか | 5段階 |
| 3 | 講師の説明は分かりやすかったですか | 5段階 |
| 4 | 演習の量・難易度は適切でしたか | 多い／やや多い／適切／やや少ない／少ない |
| 5 | 生成AIを安全に使う自信がつきましたか（受講前と受講後） | 5段階×2 |
| 6 | 最も役立った章・演習（複数選択可） | 第1〜10章、演習1〜14 |
| 7 | 第10章は企画トラック／開発トラックのどちらでしたか。内容は適切でしたか | 選択＋5段階 |
| 8 | 明日から実践すること | 自由記述 |
| 9 | 改善してほしい点 | 自由記述 |
| 10 | 3か月後のフォローアップ（実践状況の確認）への協力 | 可／不可 |

> アンケートの自由記述は、次回以降の改善のために Excel の Copilot で分類・集計できます（演習9と同じ方法）。
> 分析の際は、受講者の氏名など個人を特定できる情報を除いてから行ってください。
