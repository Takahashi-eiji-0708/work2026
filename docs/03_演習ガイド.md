# 演習ガイド

## 演習の共通ルール

- 演習素材は `materials/` フォルダにあります。**素材は直接編集せず、コピーして自分の OneDrive に保存** してから使ってください
- ファイル名の先頭に自分の名前を付けます（例：`山田_演習6_議事録.docx`）
- プロンプト例は **そのまま使っても、自分の言葉に変えても構いません**。結果が期待と違ったら、追加の指示で直してみましょう
- 各演習の最後にある **セキュリティチェック** を必ず確認してください
- Copilot の出力は毎回変わります。解答例（`materials/解答例/`）は「一つの完成イメージ」です

## 演習1 基本操作ツアー（第2章・15分）

**ねらい**：Copilot アプリの基本操作に慣れる

**手順**

1. Microsoft Edge で Copilot を開き、Microsoft 365 Premium のアカウントでサインインしていることを確認する
2. 新しいチャットを開き、次のプロンプトを入力する

```
法人向けの研修会社の営業担当者が、初めて訪問する顧客との商談で気をつけるべきことを5つ教えてください。
```

3. 回答の下にある操作で **再生成** し、1回目との違いを確認する
4. 続けて次のように入力し、会話で結果を直せることを確認する

```
今の5つを、新人営業向けに1つ30字以内で言い直してください。
```

5. 応答モードを「じっくり考える」モードに切り替えて、同じ質問をしてみる（画面に表示される名称を確認）
6. 設定画面を開き、**プライバシー（会話データの扱い）に関する設定項目** がどこにあるか確認する（第3章で使います）
7. 新しいチャットを開き、前の会話の内容が引き継がれていないことを確認する

**確認ポイント**
- [ ] 同じ質問でも回答が変わることを確認した
- [ ] 追加の指示で回答を直せた
- [ ] プライバシー設定の場所を確認した

## 演習2 プロンプト改善ドリル（第2章・20分）

**ねらい**：4要素（役割・目的・前提・出力形式）で結果が変わることを体感する

**手順**

1. 次の「悪いプロンプト」を入力し、結果を見る

```
研修のメールを書いて
```

2. 4要素を補って書き直す。次の空欄を埋めて入力する

```
あなたは【役割】です。
【目的】のために、【何を】作成してください。
前提：【相手・状況・条件】
出力形式：【形式・分量】
```

3. 2つの結果を比べ、良くなった点を3つ書き出す
4. **発展**：次のプロンプトで、Copilot 自身にプロンプトを改善させる

```
次のプロンプトを、より良い結果が得られるように改善してください。
改善したプロンプトと、改善した理由を示してください。
プロンプト：「研修のメールを書いて」
```

**確認ポイント**
- [ ] 4要素を含むプロンプトを書けた
- [ ] 結果の違いを具体的に説明できる

## 演習3 顧客・業界の事前調査（第2章・20分）

**ねらい**：Web 検索つきの調査と、出典の確認を体験する

**使う素材**：`01_顧客プロフィール.docx`（読むだけ。Copilot には貼り付けない）

**シナリオ**：みなと精機は架空の会社なので、Web で調べても情報は出てきません。
そこで、**顧客が属する業界（精密部品製造業）** について調べ、ヒアリングの仮説を作ります。

**手順**

1. 顧客プロフィールを読み、顧客の業界・規模・課題を把握する
2. Copilot アプリで次のように依頼する（Web 検索をオンにする）

```
日本の精密部品製造業（自動車部品・医療機器部品）で、
人材育成とDX推進について最近話題になっている課題を3つ教えてください。
それぞれに根拠となる出典（公的機関の資料や報道）を付けてください。
```

3. 出典リンクを **少なくとも2つ開き**、回答の内容が本当に書かれているかを確認する
4. 確認できた内容をもとに、次のように仮説を作らせる

```
上の調査結果を踏まえて、従業員850名規模の精密部品メーカーの人事課長が
「若手技術者向けDX研修」を検討している背景として考えられる仮説を3つ挙げてください。
それぞれ、ヒアリングで確かめるための質問を1つずつ付けてください。
```

**確認ポイント**
- [ ] 出典を開いて内容を確認した（確認できなかった情報はメモに「未確認」と書く）
- [ ] 手元の商談メモや顧客プロフィールを Copilot に貼り付けていない

**セキュリティチェック**：調べたのは公開情報だけか？（判定 A の情報のみ）

## 演習4 入力OK/NG判定とマスキング（第3章・25分）

**ねらい**：入力してよい情報を判定し、マスキングして安全に使う

**使う素材**：`02_マスキング演習素材.docx`

**手順**

1. 素材の①〜⑩を読み、**A（入力可）／B（加工すれば可）／C（入力不可）** を判定して表に記入する（Copilot は使わない。自分で考える）

| No | 判定 | 理由・加工方法 |
|---|---|---|
| ① | | |
| … | | |

2. 講師の解説を聞き、判定を確認する
3. 判定に基づいて、Copilot に入力する **加工済みメモ** を作る（C を削除し、B を加工する）
4. 加工済みメモを使って、次のように依頼する

```
次のメモは、法人向け研修会社の営業が初回訪問の前に書いたものです（社名は伏せています）。
初回ヒアリングで確認すべき質問を、「背景」「対象者」「内容」「条件（時期・予算）」「進め方」の
5つの分類で、各2〜3問、表形式で作ってください。

メモ：
（ここに加工済みのメモを貼り付ける）
```

**解答（講師の解説後に確認）**

| No | 判定 | 理由・加工方法 |
|---|---|---|
| ① | A | 会社ホームページで公開されている情報 |
| ② | A | ニュースリリースで公開済み |
| ③ | C | 個人の連絡先。目的に不要なので削除する |
| ④ | C | 顧客の未公開情報。秘密保持の対象 |
| ⑤ | C | 特定個人の人事評価。特に慎重に扱うべき個人情報 |
| ⑥ | B | 「競合は1名あたり中程度の価格帯で提案」と一般化する（社名・金額を伏せる） |
| ⑦ | C | 自社の社外秘の価格方針 |
| ⑧ | B | 社名を伏せ「製造業A社」として条件だけを使う |
| ⑨ | C | 認証情報。絶対に入力しない（そもそもメモに書かない） |
| ⑩ | A | 一般的な業界動向 |

> **補足**：①② は公開情報ですが、①②と⑧を組み合わせると会社が特定できます。
> 本研修の環境（個人向け契約）では、**社名を伏せて使う** のを基本にします。

**確認ポイント**
- [ ] C の情報をすべて取り除いた
- [ ] B の情報を加工した
- [ ] 加工済みメモから顧客が特定できないか、もう一度確認した

## 演習5 ヒアリングシートの作成（第4章・30分）

**ねらい**：Word の Copilot で、白紙から実務で使える文書を作る

**使う素材**：演習3の仮説、演習4の質問案

**手順**

1. Word で新規文書を作り、OneDrive に `（名前）_演習5_ヒアリングシート.docx` として保存する
2. Copilot で下書きを依頼する

```
法人向け研修会社の営業が、初回訪問で使うヒアリングシートを作ってください。
顧客は製造業の人事課長と製造部門の部長で、若手技術者向けのDX研修を検討しています。
所要時間は60分です。

構成：
1. 訪問の目的（冒頭で伝える一言）
2. ヒアリング項目の表（分類／質問／聞き取り欄／重要度）
3. こちらから伝えること（当社の強み、進め方）
4. 次回アクションの確認欄

分類は「背景」「対象者」「内容」「条件（時期・予算）」「進め方・意思決定」とし、
重要度は ◎○△ で示してください。
```

3. 生成された表の質問に、演習3・4で考えた質問が入っているか確認し、足りなければ追加を依頼する

```
「過去に受けた研修で良かった点・不満だった点」と「効果測定の考え方」についての質問を追加してください。
```

4. 質問を1つ選択し、Copilot の **書き換え** で表現を柔らかくする
5. 体裁を整えて保存する

**確認ポイント**
- [ ] 60分で聞ききれる分量になっているか（多すぎる場合は重要度 ◎ に絞る指示を出す）
- [ ] 予算など聞きにくい質問が、失礼のない表現になっているか

## 演習6 商談議事録の作成（第4章・35分）

**ねらい**：長い文字起こしから、正確な議事録を作る

**使う素材**：`03_商談文字起こし_初回訪問.docx`

**手順**

1. 素材をコピーし、`（名前）_演習6_議事録.docx` として OneDrive に保存する
2. **セキュリティ前処理**：文書内の **高野さんの携帯電話番号** を探して削除する（Ctrl＋F で「080」を検索）
3. Copilot ウィンドウで、まず内容を把握する

```
この文字起こしの内容を3行で要約してください。
```

4. 議事録を依頼する（Copilot の下書き機能で新規文書に作らせてもよい）

```
この文字起こしをもとに、社内共有用の商談議事録を作成してください。

構成：
1. 会議の概要（日時・場所・出席者）
2. 背景・目的
3. 確認した要件（対象・期間・時期・予算・内容の要望・効果測定）を表で
4. 懸念・課題
5. 決定事項
6. 次回までのアクション（担当・内容・期限の表）

条件：
- 会議日は2026年10月6日（火）です。「来週金曜」などの相対的な日付は、具体的な日付と曜日に直してください
- 明確に合意されたことだけを決定事項にしてください
- 雑談や、業務に関係しない話は除いてください
- 文字起こしの誤変換は、文脈から正しく直してください
- 担当者や期限がはっきりしない場合は「要確認」と書いてください
```

5. 出力を **文字起こしと照合** し、次の点を確認・修正する
   - 期限の日付と曜日（10/13（火）・10/16（金）・10/20（火））
   - 予算の金額と条件（税別600万円、超える場合は11月中旬の予算会議）
   - 誰が何をするか
6. 解答例 `解答例_演習6_商談議事録.docx` と比べ、抜けている項目がないか確認する

**確認ポイント**
- [ ] 相対的な日付が具体的な日付になっている
- [ ] 決定事項とアクションが文字起こしと一致している
- [ ] 雑談（ゴルフの話）と携帯電話番号が入っていない

**セキュリティチェック**：議事録を社外に送る場合、競合情報・予算の内部事情が入っていないか？

## 演習8 上長への商談報告と行動リスト（第5章・25分）

**ねらい**：社内向けの簡潔な報告と、抜け漏れのない行動リストを作る

**手順**

1. 議事録をもとに、上長（森田課長）への報告を依頼する

```
この議事録をもとに、上長の森田課長への商談報告をチャット用に作成してください。
次の型で、全体で300字以内にしてください。
【結論】受注確度（A/B/C）と次のマイルストーン
【ポイント】ニーズ／決め手／リスク（各1行）
【ご相談】上長に相談したいこと
【次の一手】日付つきの予定
```

2. 「受注確度」の判断は Copilot に任せず、**自分で決めて** 修正する（判断の理由も考える）
3. 自分の行動リストを作る

```
この議事録から、ELIソリューションズ側（自分と中川さん）が行うべきことと、
顧客側の対応のうち自分がフォローすべきことを抜き出し、
「No／アクション／担当／期限／状態」の表にしてください。
期限は具体的な日付と曜日で書き、状態はすべて「未着手」または「待ち」にしてください。
期限が決まっていないものは、次回打ち合わせ（10月20日）から逆算して提案してください。
```

4. 表を確認し、自分で気付いたアクション（例：講師のアサイン相談）を追加する

**確認ポイント**
- [ ] 報告は結論から書かれている
- [ ] 行動リストに担当と期限がすべて入っている

> **気付き**：演習6〜8では、同じ情報を何度もプロンプトに書き、同じ確認を繰り返しました。

## 演習9 研修実績データの分析（第6章・40分）

**ねらい**：Excel の Copilot で分析し、提案の根拠となる数字を見つける

**使う素材**：`04_研修実績データ.xlsx`（160件・2023〜2025年度の架空の実績）

**手順**

1. 素材をコピーして OneDrive に保存し、Excel で開く（データはテーブルになっています）
2. **データの品質を確認する**

```
このデータで、分析の前に直したほうがよい点（表記のゆれ、空欄など）はありますか？
```

   → 「顧客業種」の **「製造」「情報通信」という表記ゆれ** と、**満足度の空欄（1件）** が見つかるはず。
   表記ゆれを「製造業」「情報通信業」に直す（置換機能か、Copilot に依頼）

3. 全体の傾向をつかむ

```
このデータから分かる傾向を3つ教えてください。
```

4. 提案の根拠を探す

```
「現場課題演習」があり／なしで、満足度・理解度テスト平均・3か月後実践率の平均を比較してください。
```

```
顧客業種が製造業で、カテゴリが「DX」または「データ活用」の研修に絞って、
現場課題演習のあり／なしで3か月後実践率を比較し、件数も示してください。
```

```
実施形式（集合／オンライン）で満足度を比較し、グラフにしてください。
```

5. **検算**：ピボットテーブルを自分で作り、Copilot の結果と同じか確認する
6. 自由記述を分析する（「アンケート自由記述」シート）

```
自由記述を内容で5つ程度のグループに分け、グループごとの件数と代表的なコメントを表にしてください。
```

7. 提案に使える「根拠となる一文」を作り、メモしておく（演習11で使います）
   - 例：「当社の2023〜2025年度の実績160件では、現場課題演習を取り入れた研修の3か月後実践率は約60%で、取り入れていない研修（約38%）より約20ポイント高い」

**確認ポイント**
- [ ] 表記ゆれを直してから分析した
- [ ] 重要な数字をピボットテーブルで検算した
- [ ] 件数（n数）も確認した

**発展**：「年度ごとに、現場課題演習ありの割合がどう変化しているか」を分析してみる

## 演習10 見積試算表の作成（第6章・30分）

**ねらい**：Copilot に数式を作らせ、人が確認して正しい見積を作る

**使う素材**：`05_見積単価表.xlsx`（「単価表」「割引ルール」「見積試算」の3シート）

**前提条件（議事録より）**：受講者60名、1クラス最大20名、1人3日、集合形式、みなと精機の会場で実施

**手順**

1. 「見積試算」シートの前提条件に値を入力する（クラス数は数式で求める）

```
「見積試算」シートの B5 に、受講者数（B4）と1クラスの最大人数20名から、必要なクラス数を求める数式を入れてください。
```

2. 各項目の数量を Copilot と一緒に考える

```
単価表の各項目について、前提条件（B4〜B8）から数量を計算する数式を「見積試算」シートの D列に入れたいです。
講師料・アシスタント講師料・会場使用料・配信運営費は「クラス数×日数」、教材費は「受講者数×日数」、
事前アセスメントは「受講者数」、カスタマイズ費と効果測定は「1」です。
会場使用料は会場が「ELI会場」の場合のみ、配信運営費は実施形式が「オンライン」の場合のみ数量が入るようにしてください。
```

3. 単価（C列）・小計（E列）・割引（F列）・金額（G列）・合計の数式を作る。割引は「割引ルール」シートに従う
4. **検算**：講師料だけ電卓で計算し、数式の結果と一致するか確認する
5. 合計が予算（税別600万円）に収まっているか確認し、予算との差額を表示する行を追加する
6. 解答例 `解答例_演習10_見積試算.xlsx` の合計（4,447,500円）と比べる

**確認ポイント**
- [ ] 生成された数式を1つずつ読んで意味を確認した
- [ ] 割引の条件（50名以上、3クラス以上）が正しく反映されている

**発展**：「オンライン形式に変えた場合の合計」を前提条件の変更だけで確認する
