# 研修企画書：ソリューション営業のための生成AIセキュア活用実践

## 1. 背景

生成AIは「試す段階」を過ぎ、日常の業務ツールに組み込まれる段階に入りました。
Microsoft 365 では Word・Excel・PowerPoint の中から Copilot を呼び出せるため、
営業担当者は **普段の資料作成の流れを変えずに** 生成AIを使えます。

一方で、営業の現場には次のような課題があります。

- 顧客情報・商談内容など **機密性の高い情報** を扱うため、「どこまで入力してよいか」が分からず使えていない
- 使ってはいるが単発の質問にとどまり、提案書・見積・議事録といった **業務の成果物** に結びついていない
- 生成結果をそのまま使ってしまい、**事実誤り（ハルシネーション）** に気付かない

本研修では、1件の提案活動を最初から最後まで Copilot で進める体験を通して、
**「安全に」「成果物まで」「自分の業務で」** 使える状態を目指します。

## 3. 到達目標

研修終了時に、受講者は次のことができるようになります。

1. 生成AIの進化の流れと得意・不得意を説明し、業務のどこで使うかを判断できる
2. Copilot に目的・前提・出力形式を伝えるプロンプトを書き、対話しながら結果を改善できる
3. 入力してよい情報／いけない情報を判断し、マスキング・ファクトチェックを実践できる
4. Word・Excel・PowerPoint の Copilot を使い、議事録・分析・見積・提案書・提案スライドを作成できる
5. 商談後の作業を支援するアプリの仕組みを理解し、自分の業務への適用案をまとめられる

## 4. 研修の特長

### 4.1 1件の提案活動を通して学ぶストーリー型演習

受講者は **ELIソリューションズ** の営業担当者として、架空の顧客 **みらい商事株式会社** に
「法人営業20名向けの生成AI活用研修」を提案します。

| 項目 | 顧客の状況（架空） |
|---|---|
| 会社 | みらい商事株式会社（東京都）。全社約300名 |
| 窓口 | 佐藤 美和 様（人材開発担当）、田中 淳 様（営業企画担当） |
| 相談内容 | 生成AIの利用状況に部署・担当者で差がある。法人営業の担当者20名向けの研修を検討（他部署展開は別途） |
| IT環境 | Microsoft 365 を利用。一部の部署で Copilot を試行中 |
| 時期 | 11月上旬を希望（日付・会場は未確定。会場・端末・ライセンスは顧客手配） |
| 予算 | 目安100万円（**承認済みの上限ではない**） |
| 提案 | **A案** 集合研修2日間＋教材 60万円／**B案** A案＋事前診断＋受講後1か月の活用フォロー 100万円（税抜） |
| 決裁 | 人材開発担当の上長が判断。**最終的な承認者は金額確定後に確認** |
| 未確定事項 | 対象20名の Copilot 利用可否、A案の場合のフォロー担当、予算承認 |
| 日程 | 初回訪問 10/6（火）→ 骨子送付 10/9（金）→ 資料受領 10/12（月）・10/13（火）→ 提案 10/16（金）14:00 → 研修 11月上旬 |

予算が承認前で最終承認者も決まっていないため、受講者は「上長に説明できる提案（上長説明用の1枚）」と
「決まっていないことを決まっていないものとして残す確認事項の一覧」も作ります。すべての演習が一つの提案活動につながっているため、
Day 2 の終わりには **提案書・見積書・提案スライドの一式** が手元に残ります。

```
顧客調査 → ヒアリング準備 → 商談議事録 → フォローメール → 社内報告
      → 実績データ分析 → 見積試算 → 提案書 → 提案スライド
```

### 4.2 セキュリティを「知識」ではなく「習慣」として身につける

- 第3章でルールを学んだ後も、すべての演習に **「セキュリティチェック」欄** を置き、毎回確認します
- 演習素材には、あえて個人情報や未公開情報を紛れ込ませています。受講者はそれに気付き、マスキングしてから Copilot に渡します
- Microsoft 365 Premium（個人向けプラン）と法人向け Copilot の **データ保護の違い** を理解し、自社で業務データを扱う際の判断基準を持ち帰ります

### 4.3 自社アプリを題材にした「応用の考え方」

最後の約1/4では、商談後の作業（議事録・メール下書き・行動管理）を支援する自社アプリ
**ELI Sales Assist** を紹介します。Office で手作業でやった内容がアプリでどう自動化されるかを見たうえで、
受講者自身の業務に置き換えて適用案をまとめます。
開発環境がある受講者は、**Codex で同じアプリを段階的に作り、動かしながら不具合を修正する** 流れを体験します。

## 6. 事前準備のお願い

- 受講者ごとに **Microsoft 365 Premium** が有効な Microsoft アカウントを用意してください
- Word・Excel・PowerPoint で Copilot を使うには、**ファイルを OneDrive に保存（自動保存オン）** しておく必要があります
- 研修では **架空のデータのみ** を使います。実際の顧客情報・社内情報は持ち込まないでください
- 開発トラック参加者は、Codex を使える環境（ChatGPT の対応プランへのサインイン、または API キー）と Python 3.11 以上を用意してください
