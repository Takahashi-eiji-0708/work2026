# ミニ演習集（全章）

各スライドの直後に行う2〜5分の短い演習です。講義で学んだことを **その場で確かめる** ために使います。

- 番号は「章-番号」（最近のトピックは T、Day 2 冒頭の復習は D2、発表とまとめは S）。スライドのミニ演習と同じ番号です
- 特に指示がない限り **Copilot は使わず**、紙か Word で答えます（判断の練習に集中するため）
- 解答はスライドの「解答」ページと、この資料の各演習の下にあります
- 優先度：◎ 必須（時間配分に組み込み済み）／○ 推奨（講義の説明を短くして実施）／△ 時間があれば（復習・宿題にしてもよい）

### 3-4 文字起こしをマスキングする（4分・◎）

```
話者B: みらい商事、人材開発担当の佐藤美和です。隣に営業企画担当の田中淳も同席しています。
話者B: 予算は100万円程度を目安に見ています。ただ、これは承認済みの上限ではありません。
話者C: 私のほうで持てるかどうかは、上長と相談してからになります。
```

**解答例**

```
話者B: 商社A社、人材開発担当の顧客担当者Bです。隣に営業企画担当の顧客担当者Cも同席しています。
話者B: 予算の目安はあるが、まだ承認されていない。
話者C: 受講後の支援担当は、上長と相談して決める予定。
```

長い語（「佐藤美和」）から置き換える。先に「佐藤」を置き換えると「顧客担当者B美和」になり、下の名前が残ってしまう。金額は目的に必要なければ一般化する。「佐藤美和＝顧客担当者B」のような対応表は手元だけに置き、Copilot には渡さない（渡すと置き換えた意味がなくなる）。
