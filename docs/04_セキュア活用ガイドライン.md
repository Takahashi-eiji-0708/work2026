# 生成AIセキュア活用ガイドライン（持ち帰り用チェックシート）

> 研修で学んだルールを1枚にまとめたものです。職場で使う前に、**自社のガイドラインを優先** してください。

## 使う前に：環境の確認

- [ ] 使っている Copilot は **会社が認めた契約・アカウント** か（個人向けプランを業務に使ってよいか確認済み）
- [ ] 会話データの扱い（学習への利用・保存期間）の **設定を確認** した
- [ ] ファイルの保存先と **共有範囲** を確認した

## 入力する前に：3段階判定

| 判定 | 内容 | 対応 |
|---|---|---|
| **A 入力可** | 公開情報・一般知識・自分で書いた一般的な文章 | そのまま入力してよい |
| **B 加工すれば可** | 社名・人名・金額などを伏せれば使える情報 | **置換・一般化・削除・抽象化** してから入力 |
| **C 入力不可** | 個人情報、顧客の未公開情報、秘密保持契約の対象、社外秘の方針、ID・パスワード | **入力しない** |

**迷ったら**：「社外の掲示板にそのまま貼られても問題ないか？」→ 問題があれば入力しない。

## 出力を使う前に：5つの確認

- [ ] **数字**：元データ・一次情報で確認した（計算は Excel で検算）
- [ ] **固有名詞**：社名・人名・役職を名刺・CRMで確認した
- [ ] **日付**：相対的な日付を具体的な日付にし、曜日を確認した
- [ ] **出典**：リンクを開いて内容を確認した
- [ ] **約束・決定事項**：自分の記録と照合した

## 社外に出す前に

- [ ] 競合情報・予算の内部事情・社内の相談事項が混ざっていない
- [ ] 他社の商標・表現に似ていない。生成画像の利用条件を確認した
- [ ] 送信・提出は **自分で内容を読んでから** 行う

## 気をつける場面

- 他人から受け取ったファイル・Webページを要約させるとき → **隠れた指示（プロンプトインジェクション）** に注意
- AIが自動でメール送信・ファイル操作をする機能を使うとき → **実行前に内容を確認**
- アプリや自動化を作るとき → **API キーをコードに書かない**、ログに機密を出さない

## 困ったときは

**使わずに、上長・情報システム部門に相談する。**
誤って入力してしまった場合も、すぐに報告する（会話履歴の削除だけで済ませない）。
